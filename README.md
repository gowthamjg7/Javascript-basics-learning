# JavaScript Practice – Calculator & Student Grading System

This repository contains two beginner-level JavaScript programs created as part of my Full Stack Development Mentorship Program at Bala Labs.

## Programs Included

### 1. Simple Calculator Using Switch

A basic calculator that performs arithmetic operations based on the selected operator.

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Handles division by zero
- Displays a message for invalid operators

### 2. Student Marks, Grade, Result & Remarks

A program that calculates the final marks by adding bonus marks and determines the student's grade, result, and remark.

- Adds bonus marks to the original marks
- Assigns grades based on the final score
- Determines Pass or Fail using the ternary operator
- Displays remarks using a `switch` statement

## Concepts Practiced

- Variables using `let`
- Arithmetic operators
- Conditional statements (`if`, `else if`, `else`)
- `switch` statements and `break`
- Comparison and logical operators
- Ternary operator
- Basic error handling for division by zero
- Console output using `console.log()`


## Learning Goal

To strengthen my understanding of JavaScript fundamentals through practical coding exercises.
